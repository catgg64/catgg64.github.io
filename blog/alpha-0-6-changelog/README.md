# Alpha 0.6 changelog

## Menu
- Added a delte buttom
- Made all of the sections farther apart from each other
- Added an options menu, with only a fullscreen toggle for now
- Added a version count to the bottom left of the menu
- Better resizing
- Switched tween animation

## Internal
- Added a version count to the saves
- Now the player saves save independently from the world save, allowing for mutliple people to play in the same world, usefull for the multiplayer features in 0.7
- Now saves and other game stuff in the future are saves in ./.farmbotany instead of the game's content folder
- Tiles use integers instead of string literals
- Better tilemap editor ([Click here to know more](https://github.com/catgg64/Farmbotany-s-Tile-Manager))

## Content
- Added a forest room, inaccessible in this version but will be added later in beta
- Added a pause menu as well as an option to exit to the main menu (if you find any memory leaks, email me at sleepy_furret@proton.me)
