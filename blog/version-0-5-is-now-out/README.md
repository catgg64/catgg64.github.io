## Version 0.5 is now out!
Just right now, the new version for Farmbotany, v0.5, came out in the github repo (witch is private, so you can't see it but I'm going to tell it to you in here). The main purpose of this update was the full engine switch, now being CatEngine instead of pygame. This engine is much faster, since it has GPU acceleration, but there are some downsides, like the lack of transparency and the pixelation filter.
Hope all of you like the update! You may also see [the changelog](../0-5-changelog/)
